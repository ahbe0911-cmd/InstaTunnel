# InstaTunnel

یک کلاینت آزمایشی Android برای اتصال خودکار **فقط Instagram** از طریق Android `VpnService` و پراکسی‌های عمومی SOCKS5.

> هشدار امنیتی: پراکسی‌های عمومی توسط اشخاص ثالث اداره می‌شوند و ممکن است متادیتای اتصال را مشاهده کنند. محتوای HTTPS اینستاگرام همچنان توسط TLS رمزگذاری می‌شود، اما برای حساب‌های حساس استفاده از پراکسی عمومی توصیه نمی‌شود.

## منطق نسخه MVP

- مسیر VPN فقط برای `com.instagram.android`
- دریافت فهرست SOCKS5 عمومی از چند منبع GitHub
- تست واقعی SOCKS5 و اتصال به `www.instagram.com:443`
- انتخاب خودکار کم‌تاخیرترین مسیر سالم
- ساخت TUN با `VpnService`
- عبور ترافیک TUN از SOCKS5 با `hev-socks5-tunnel`
- اتصال/قطع با یک دکمه و نمایش وضعیت فارسی

## Build

GitHub Actions فایل APK دیباگ را به‌عنوان artifact با نام `InstaTunnel-APK` تولید می‌کند.
